# dsh-civ6-whale

让 DeepSeek 在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）的会话里玩《文明6》。**不需要 API Key**：思考和行动的是 DSH 自己的模型，用的是 DSH 的额度。

```
DSH 会话 ──(MCP, stdio)──> civ6-mcp（Python）──(Tuner 调试端口 4318)──> 文明6
```

插件本身不碰游戏，它只做一件事：注册三个会话预设。选了预设的会话才会拉起 civ6-mcp、拿到玩游戏的工具和说明，其他会话完全不受影响。

## 三个预设

| 预设 | AI 能做什么 | 适合 |
|---|---|---|
| 文明6·AI 自己玩 | 全部操作。自己一回合一回合地打，每隔几回合汇报一次 | 想看 AI 打 |
| 文明6·AI 当助理 | **只能查询**，不能动游戏。你问它答，给具体建议 | 自己玩，要个参谋 |
| 文明6·一起玩 | 全部操作，但按你的话来；不经你同意不结束回合 | 边聊边玩，分工合作 |

## 老会话也能玩：入口工具 civ6

DSH 规定会话聊过以后就不能再换预设。为了让已经聊过、没选预设的会话也能玩，插件默认在**所有会话**里加一个 `civ6` 工具：

- 常驻上下文里只有这一个工具的简短说明（一两百 token），不会把六十多个游戏工具塞进每个会话；
- 想玩时直接说“来玩文明6”，AI 会先调 `{"action":"help"}` 读规则和动作列表，之后每个动作都是 `{"action":"动作名","args":{参数}}`；
- 第一次用到时插件才在后台启动 civ6-mcp，玩法默认“一起玩”（配置里可以改成另外两种）；
- 游戏没开或没进对局时，会直接告诉 AI 连不上，不会卡住。

和预设比：预设里每个动作是独立的工具，参数检查更严格，规则一开始就在上下文里，专门开会话玩体验更好；入口工具胜在随时随地。两者可以同时用，但同一时间只有一个能操作游戏（见“已知限制”）。

**随时接手**（“AI 自己玩”和“一起玩”）：说“我来”“停一下”，AI 会交出操作权，之后它所有改动游戏的操作都会被 civ6-mcp 拒绝，只能查询和给建议；说“你来”“继续”再交还给它。想立刻打断正在进行的操作，直接点 DSH 的停止按钮。

## 需要什么

1. **文明6**（Steam 版），打开 Tuner：选项里的 “Tuner (disables achievements)”，或者把
   `%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VI\AppOptions.txt` 里的 `EnableTuner` 改成 `1`（游戏关着时改）。
   开着 Tuner 时**成就会被禁用**。同时关掉“自动结束回合”，用窗口化。不需要装 SDK。
2. **civ6-mcp** 的 `base-game-compat` 分支（在 [lmwilki/civ6-mcp](https://github.com/lmwilki/civ6-mcp) 的基础上加了原版兼容和三种模式），以及 [uv](https://docs.astral.sh/uv/)。在仓库目录运行一次 `uv sync`。
3. **DSH**。

## 安装（从本地文件夹）

DSH 的桌面版和网页版用不同的 profile（`<DSH_HOME>/profiles/desktop`、`profiles/web`），要用哪个就在哪个里装：

1. profile 的 `package.json`：`dependencies` 加 `"dsh-civ6-whale": "link:<本仓库路径>"`，`dsh.profile.bundles` 加 `"dsh-civ6-whale"`；
2. 在 profile 目录用 DSH 自带的 pnpm 运行 `pnpm install --no-frozen-lockfile`；
3. 重启 DSH。

## 怎么玩

1. 启动文明6，进入一局对局（停在主菜单时读不到局面）。
2. 在 DSH 里**新建会话**，发第一条消息之前选一个文明6 预设。已经聊过的会话不能换预设，这是 DSH 的规定。
3. 直接说话，比如：
   - AI 自己玩：“开始吧，目标科技胜利”
   - AI 当助理：“现在该造什么？”“这个开拓者去哪建城好？”
   - 一起玩：“开拓者原地坐城，然后你帮我选个开局生产”“这回合你来收尾”

游戏进度在存档里，AI 每回合结束时写的反思存在 civ6-mcp 的日记里，新会话可以用 `get_diary` 接着之前的思路玩。

## 设置

DSH 左侧边栏「插件」→ dsh-civ6-whale → 「配置 ›」。所有设置都要**重启 DSH 并新建会话**才生效。

| 设置 | 默认 | 说明 |
|---|---|---|
| 创建三个预设 | 都开 | 不想要哪个就关掉 |
| 额外要求 | 空 | 比如“走科技胜利，前 50 回合至少铺 4 座城” |
| 原版规则（没有资料片） | 开 | 隐藏总督、着力点、世界议会这些原版没有的工具。启用了“风云变幻”就关掉 |
| civ6-mcp 文件夹 | `E:\Projects\civ6-mcp` | 里面有 `pyproject.toml` 的那个文件夹 |
| uv 路径 | 空（自动找） | 找不到时填 `uv.exe` 的完整路径 |
| 单个动作最长等多少分钟 | 10 | 后期结束回合要等所有 AI 文明走完 |
| 三个预设的名字、基础预设 | | 基础预设默认 `standard` |

改了 `lib/index.js` 的 `Config` 以后运行 `npm run build:client` 重新生成配置卡片 `lib/client.js`。

## 已知限制

- **游戏顾问**（选项 → 游戏 → 教程/顾问）：顾问提示弹出来时，游戏会停下等你点掉，电脑文明的回合也跟着停。civ6-mcp 结束回合时会自动把它关掉；想清净一点可以直接在选项里把顾问设成“禁用”。
- **同时只能有一个文明6 会话**：游戏只允许一个 Tuner 连接。开着 SDK 的 FireTuner.exe 也会占掉这个连接。
- AI 思考时游戏不会暂停。文明6 是回合制，单人游戏里这不要紧。
- 接手靠的是你说一句话或者点停止按钮，游戏里没有快捷键。
- 原版兼容只验证过查询类工具；移动、建城、结束回合等操作沿用上游的实现，在原版上还没有逐个实测。
- 没有自动安装：civ6-mcp 要自己放好。
